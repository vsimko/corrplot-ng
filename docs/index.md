# corrplot-ng documentation

This directory stores project knowledge in the [Open Knowledge Format (OKF)](https://github.com/GoogleCloudPlatform/open-knowledge-format).

Each document uses Markdown with YAML frontmatter. Keep the text clear and direct. Use simple English and follow the principles of ASD-STE100 where practical.

## Documents

- [Future vision](future-vision.md): goals, possible design, and development steps.
- [Catalog of diagrams and visualizations](diagram-catalog.md): current compatibility targets and ideas for future visualizations.

## Writing rules

- Write all repository content in English.
- Use short sentences and common words.
- Give each document one clear purpose.
- Mark ideas as planned or proposed until the team confirms them.
- Do not describe a feature as implemented until code and tests support that claim.
- Link to related documents with relative Markdown links.
