# Rust / rextendr scene-v1 benchmark spike

This isolated package implements the experimental scene-v1 JSON builder
through an R binding generated by rextendr. It depends on the same local
`crates/corrplot-core` library as the standalone CLI; matrix shape, labels,
missing values, finite values, and correlation semantics are validated by
that shared crate rather than by a copied Rust implementation.

The exported `build_scene_json_rust(labels, matrix, annotation)` function
preserves missing values as JSON `null`, emits cells in row-major order, and
uses the same geometry and style constants as the other candidates.

CI generates a disposable R package with `prepare-r-package.R`, compiles it
with the Rust stable toolchain, and installs it for the shared benchmark
harness. Generated package files and Cargo build output are not committed.

This remains an integration proof, not a production R-package migration. It
demonstrates one compiled validation operation shared with the CLI. CI verifies
offline source-package installation and `R CMD check --as-cran` on Linux,
macOS, and Windows, plus Windows binary installation without Rust on PATH.
Rust/Cargo 1.78 is the declared and CI-tested minimum. One CRAN-style NOTE
remains for Cargo vendor checksum/provenance metadata required by offline
builds; actual CRAN acceptance and production R migration remain unproven.

The 2026-10-31 Ubuntu 24.04 / R 4.6.2 run measured a 1,314,220-byte source
tarball and a 6.0 MB installed package (5.9 MB in `libs`). The installed size
exceeds rextendr's 5 MB caution and requires CRAN guidance before production
use. Controlled human maintainer time versus the C++/Rcpp path remains
unmeasured; existing effort ranges are planning estimates only.

The generated R Cargo package uses a size-oriented release profile
(`opt-level = "z"`, LTO, one codegen unit, and debuginfo stripping). This
profile is set in the generated package manifest because Cargo profiles in
the separate CLI package do not apply to it. CI records the installed package,
native library, and Rust static-library artifact sizes on Linux, macOS, and
Windows, and prints the R integration's normal dependency tree. The R
integration depends on `corrplot-core` and `extendr-api`; it does not depend
on or build the CLI package. See
[`docs/rust-rextendr-size-optimization.md`](../../docs/rust-rextendr-size-optimization.md)
for the rationale and measurement limits.
