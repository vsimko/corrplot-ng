# Rust / rextendr scene-v1 benchmark spike

This isolated package implements the same experimental scene-v1 JSON builder
as the Python reference and C++/Rcpp candidate. It returns the canonical scene
as JSON through an R binding generated by rextendr.

The exported `build_scene_json_rust(labels, matrix, annotation)` function
preserves missing values as JSON `null`, emits cells in row-major order, and
uses the same geometry and style constants as the other candidates.

CI generates a disposable R package with `prepare-r-package.R`, compiles it
with the Rust stable toolchain, and installs it for the shared benchmark
harness. Generated package files and Cargo build output are not committed.

This remains an experiment. It does not select Rust for production, establish
clean Windows binary-install readiness, or change the legacy R package.
